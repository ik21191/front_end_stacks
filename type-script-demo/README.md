# Run the application
Make sure the `node.js` is installed in your system. 

Then run below command to install `TypeScript`. 

```
npm install -g typescript
```

1. Run below command to create `.js` file.
```
tsc app.ts
```
This will create `app.js` file.

2. Run below command to execute the `app.js`
```
node app.js
```
