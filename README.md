# front_end_stacks
This repo contains some demo examples of different front end technology stacks.

# Steps to create and run React App with TypeScript using Vite

```
npm create vite@latest my-react-ts-app -- --template react-ts
```

## Navigate into the project folder
```
cd my-react-ts-app
```

When asked
- Which linter to use? : Select `ESLint`
- Install with npm and start now? : Select `Yes`

## Install dependencies
```
npm install
```

## Start the development server in HMR
**HMR** : Meaning any changes you save in your code editor will instantly update in your browser without requiring a manual refresh.
```
npm run dev
```

# Steps to run the React app after cloning

- `cd path/to/your/existing-react-app`
- Install the dependencies : `npm install`
- Start the development server : `npm run dev`
